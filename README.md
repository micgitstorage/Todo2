# Fokus – moderne Todo-App

Enthält modernes iPhone-Design, Dark Mode, Prioritäten, Fälligkeitsdaten, Suche, Filter, Sortierung, Bearbeiten, Statistiken, lokale Speicherung und Offline-Modus.

## Veröffentlichung
Alle Dateien direkt in ein GitHub-Repository hochladen. Unter **Settings → Pages** `main` und `/(root)` wählen. Danach die URL in Safari öffnen und **Teilen → Zum Home-Bildschirm** auswählen.

Die Aufgaben werden lokal im Browser gespeichert und nicht in die Cloud synchronisiert.
